# 跨平台视频播放器

一个本地运行的飞书多维表格视频浏览测试页。按飞书视图读取记录，支持按平台筛选、切换视频及显示「视频爆了」「评论区佐证」。读取时使用本机 lark-cli 的用户身份，不在前端保存飞书凭据。

## 运行

需要 Python 3、已配置并以用户身份授权的 `lark-cli`，以及目标多维表格的读取权限。创建不纳入 Git 的 `config.local.json`：

```json
{"base_token":"你的 Base token","table_id":"你的数据表 ID","view_id":"你的视图 ID"}
```

也可以分别设置 `FEISHU_BASE_TOKEN`、`FEISHU_TABLE_ID`、`FEISHU_VIEW_ID` 环境变量。运行 `python3 server.py`，然后打开 `http://127.0.0.1:8765/`。页面初次打开和点击刷新时读取在线数据；临时查询文件在请求结束后删除。

本程序仅监听本机，不适合直接部署到公网。线上多人使用需要单独实现用户认证、授权、访问控制和安全的数据服务。各平台的嵌入播放器受原平台权限和网络条件限制；自动播放和预加载不保证可用。
